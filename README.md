# OneChat Desktop v0.3.0

## Release Testing Build

This folder contains the official OneChat Desktop installer.

This is the **OneChat v0.3.0 Release Testing Build**.

The purpose of this testing build is to allow testers to use OneChat, find bugs, test features, improve the application, and provide feedback before future releases.

## Installer

Run:

`OFFICIALONECHAT Setup 0.3.0.exe`

to install OneChat on Windows.

After installation, launch OneChat from the installed application or desktop shortcut.

## Version

**Version:** 0.3.0  
**Status:** Release Testing  
**Platform:** Windows

## About

OneChat is a social platform built for connecting, chatting, and creating communities.

The goal of OneChat is to provide users with a simple way to communicate, connect with friends, and participate in communities.

## 🧪 Testing

If you are testing OneChat, please test as many features as possible.

Try testing:

- Account creation
- Login
- Logout
- Account recovery
- Navigation
- Messaging
- Friends and social features
- Profiles
- Notifications
- Settings
- Buttons and menus
- Application startup
- Application performance
- Closing and reopening OneChat
- Anything that causes errors, crashes, or unexpected behavior

Please use the application normally while also trying to find problems.

## 🐛 Bug Reports

If you find a bug, please report it.

When reporting a bug, include:

- What happened
- What you were doing when it happened
- What you expected to happen
- What actually happened
- Whether the problem happens every time
- Screenshots or screen recordings if possible
- Any error messages

The more information provided, the easier it is for the development team to reproduce and fix the problem.
