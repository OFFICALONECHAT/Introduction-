# Introduction

Welcome to OneChat — a social and communication platform designed to bring chatting, communities, servers, and more into one place.

OneChat is currently in development, with the goal of creating a modern platform where users can communicate, join communities, create servers, and interact through different features.

This repository is simply an introduction to the OneChat project — just the message you're reading right now. 😂
